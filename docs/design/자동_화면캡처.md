# 자동 화면 캡처

이 문서는 디자인 검토를 위해 주요 화면을 Playwright로 자동 캡처하는 방법을 정리한다.

## 목적

디자인을 바꾸기 전에 현재 화면을 한 번에 캡처해서 대시보드, 메모 작성, 복기 작성, 폴더, 설정, 휴지통 화면을 비교할 수 있게 한다.

## 캡처되는 화면

모바일과 데스크톱 두 크기로 아래 화면을 캡처한다.

1. 로그인
2. 대시보드
3. 메모 작성 화면
4. 복기 작성 화면
5. 폴더 목록
6. 폴더 상세
7. 설정
8. 휴지통

## 실행 방법

프로젝트 폴더에서 아래 명령을 실행한다.

```bash
DESIGN_CAPTURE_EMAIL="bokgi@test.com" DESIGN_CAPTURE_PASSWORD="bokgitest123!" npm run design:capture
```

기본 캡처 대상은 운영 배포 주소이다.

```text
https://bokgi-note.vercel.app
```

로컬 서버를 캡처하고 싶다면 먼저 개발 서버를 켠다.

```bash
npm run dev
```

그 다음 별도 터미널에서 아래처럼 실행한다.

```bash
DESIGN_CAPTURE_BASE_URL="http://localhost:3000" DESIGN_CAPTURE_EMAIL="bokgi@test.com" DESIGN_CAPTURE_PASSWORD="bokgitest123!" npm run design:capture
```

## 결과 위치

캡처 결과는 아래 폴더에 저장된다.

```text
design-captures/
```

예:

```text
design-captures/2026-06-21T22-40-00/mobile-02-dashboard.png
design-captures/2026-06-21T22-40-00/desktop-02-dashboard.png
```

`design-captures/` 폴더는 Git에 올리지 않는다.

## 디자인 검토 순서

캡처 후 아래 순서로 확인한다.

1. `mobile-02-dashboard.png`
2. `mobile-04-review-editor.png`
3. `mobile-03-note-editor.png`
4. `mobile-07-settings.png`
5. 데스크톱 화면은 보조로 확인

복기노트는 모바일 사용이 핵심이므로 모바일 캡처를 우선 기준으로 삼는다.
