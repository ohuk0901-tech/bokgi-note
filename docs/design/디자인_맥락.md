# 디자인 맥락

## 1. 문서 목적

이 문서는 복기노트의 화면 구조, UX 우선순위, 문구, 디자인 톤을 결정할 때 기준으로 삼는 디자인 맥락 문서이다.

기존 문서인 `핵심사용자_페르소나.md`, `핵심사용자_JTBD.md`, 서비스 개요, 실제 구현 흐름을 바탕으로 페르소나, JTBD, 멘탈모델, 고객 행동, 페인포인트, 감정지도, 성공 정의를 한곳에 정리한다.

복기노트는 단순 투자 일기 앱이 아니다. 사용자가 매일의 투자 판단, 감정, 행동 이유를 기록하고, 시간이 지난 뒤 다시 읽으며 자기만의 투자 세계관, 행동 원칙, 투자 근육을 키우는 조용한 복기 작업대이다.

## 2. 제품 한 줄 정의

투자 판단과 감정의 기록을 다시 읽고, 반복 패턴을 발견해, 나만의 행동 원칙으로 바꾸는 모바일 우선 복기 노트.

## 3. 핵심 페르소나

### 대표 사용자

민석은 직장인 개인 투자자이다. 전문 트레이더처럼 수익률 통계와 전략 성과를 정교하게 관리하기보다는, 자신의 판단 과정과 감정 패턴을 더 잘 이해하고 싶은 사용자이다.

### 숙련도

| 구분 | 내용 |
| --- | --- |
| 투자 숙련도 | 완전 초보는 아니며, 시장 뉴스, 포트폴리오 상태, 관심종목, 시장 심리, 자기 심리를 구분해 기록할 수 있다. |
| 약점 인식 | 수익률 계산보다 감정, 충동, 과신, 회피, 기준 없는 행동이 더 큰 문제라고 느낀다. |
| 도구 숙련도 | 아이폰 메모장처럼 단순한 기록 도구에 익숙하고, Notion의 목록/체크박스/템플릿 구조도 이해한다. |
| 선호 | 복잡한 설정, 통계, 차트보다 바로 쓰고 바로 닫을 수 있는 흐름을 선호한다. |

### 사용 빈도

| 리듬 | 사용자 행동 |
| --- | --- |
| 매일 | 투자 생각이 있는 날 5~10분 안에 투자 일기를 쓴다. |
| 주간 | 한 주의 기록을 모아 읽고, 잘한 점/아쉬운 점/다음 주 교훈을 정리한다. |
| 장기 | 1주, 3개월, 1년 뒤 과거 기록을 다시 보며 당시 판단과 현재 시각을 비교한다. |
| 수시 | 투자 원칙, 행동 원칙, 체크리스트 같은 대표 메모를 업데이트한다. |

### 시간 압박과 사용 환경

- 평일에는 장중 또는 장 마감 후 감정이 남아 있을 때 빠르게 기록해야 한다.
- 기록을 미루면 당시 판단 이유와 감정이 흐려진다.
- 주말 복기는 여유가 있지만, 여러 메모를 오가야 하면 쉽게 귀찮아진다.
- 기본 사용 환경은 iPhone Safari 또는 PWA이다.
- 데스크톱은 긴 글 작성, 설정 정리, 개발 확인용 보조 환경이다.
- 주로 혼자 쓰며, 감정과 실수를 적어야 하므로 프라이버시와 심리적 안전감이 중요하다.

### 기능별 JTBD

| 사용자가 하려는 일 | 사용자가 진짜로 끝내려는 일 |
| --- | --- |
| 투자 일기 작성 | 오늘 시장과 내 감정을 빠르게 기록해서, 나중에 왜 그렇게 판단했는지 잃어버리지 않고 싶다. |
| 이번 주 복기 | 이번 주 기록들을 한 번에 읽으며 반복된 감정, 행동, 실수를 발견하고 다음 주 원칙으로 바꾸고 싶다. |
| 1주/3개월/1년 복기 | 시간이 지난 뒤 과거의 나를 다시 보며, 당시 판단이 단기 감정이었는지 장기 기준이었는지 확인하고 싶다. |
| 대표 메모 보기 | 자주 지켜야 할 투자 원칙과 행동 기준을 판단 순간에 쉽게 꺼내 보고 싶다. |
| 복기 중 기존 메모 수정 | 깨달음이 생긴 순간 바로 행동 원칙에 반영해서, 복기가 단순 감상이 아니라 기준 업데이트로 이어지게 하고 싶다. |
| 템플릿으로 작성 | 매번 무엇을 써야 할지 고민하지 않고, 시장/포트폴리오/심리/행동을 빠짐없이 점검하고 싶다. |
| 밀린 복기 확인 | 놓친 복기를 직접 찾아다니지 않고, 다시 봐야 할 기록을 앱이 조용히 알려주면 좋겠다. |

## 5. 멘탈모델과 레퍼런스

사용자는 완전히 새로운 방식의 앱을 배우고 싶어 하지 않는다. 이미 익숙한 제품의 기대를 가져온다. 복기노트는 익숙한 구조를 최대한 따라가되, "여러 기록을 한 흐름으로 읽으며 복기한다"는 고유한 개념은 별도로 분명히 안내해야 한다.

### 그대로 따라야 할 익숙한 표준

| 레퍼런스 | 사용자가 기대하는 것 | 복기노트 적용 |
| --- | --- | --- |
| Apple Notes | 폴더 안에 메모가 최신순으로 쌓이고, 누르면 바로 편집된다. | 폴더/메모 기본 구조, 자동 저장, 단순한 목록을 유지한다. |
| Apple Notes | 새 메모는 `+`로 바로 만든다. | 폴더 안 `+`는 새 자유 메모를 즉시 만든다. |
| Notion | 템플릿으로 반복 기록을 시작하고, 체크박스/불릿/번호 목록을 자연스럽게 쓴다. | 투자 일기, 한 주 마무리, 다음 주 계획 템플릿과 TipTap 에디터를 제공한다. |
| 습관 앱 | 첫 화면에서 오늘 할 일을 바로 시작한다. | 대시보드 첫 행동은 오늘 기록과 이번 주 복기이다. |
| 트레이딩 저널 | 매매 결과뿐 아니라 판단 이유와 감정을 기록한다. | 템플릿은 뉴스, 시장 반응, 포트폴리오, 심리, 행동 이유를 포함한다. |

### 복기노트에서 새로 안내해야 할 개념

| 고유 개념 | 왜 안내가 필요한가 | 안내 방향 |
| --- | --- | --- |
| 복기 세션 | 일반 메모처럼 보이지만 내부적으로는 복기 결과이다. | 목록에서는 `복기` 뱃지로만 구분하고, 복기 화면에서 의미를 자연스럽게 드러낸다. |
| 이번 주 복기 시작 | 사용자가 폴더에서 직접 여러 메모를 고르는 방식보다 빠른 핵심 행동이다. | 대시보드에서 별도 섹션으로 명확히 보여준다. |
| 원본 읽기 전용 | 복기 중 원본은 고치는 대상이 아니라 읽는 대상이다. | 원본 영역은 편집 UI를 없애고, 복기 입력창과 시각적으로 분리한다. |
| 복기 중 기존 메모 수정 | 깨달음을 행동 원칙에 바로 반영하는 핵심 차별점이다. | "기준 메모를 고친다"는 흐름을 복기 화면에서 쉽게 발견하게 한다. |
| 다시 볼 기록 | 1주/3개월/1년 복기는 해야 할 일처럼 압박하면 부담이 된다. | "밀림"보다 "다시 볼 기록"처럼 부드러운 표현을 쓴다. |

## 6. 고객 행동 흐름

### 기본 루틴

1. 사용자는 대시보드에 들어온다.
2. `투자 일기 작성하기` 또는 `투자 일기 이어쓰기`를 누른다.
3. 템플릿을 따라 오늘의 시장, 포트폴리오, 심리, 행동 이유를 기록한다.
4. 기록은 자동 저장된다.
5. 기록은 투자 일기 폴더에 쌓인다.

### 주간 복기 루틴

1. 사용자는 대시보드에서 `이번 주 복기 시작`을 본다.
2. 이번 주 투자 일기가 자동으로 복기 원본에 들어간다.
3. 사용자는 원본을 한 화면에서 이어 읽는다.
4. 원본 사이에서 복기 내용을 작성한다.
5. 깨달은 점이 있으면 대표 메모나 행동 원칙 메모를 불러와 수정한다.
6. 복기 세션은 저장되고, 나중에 다시 복기 대상으로 쓸 수 있다.

### 장기 복기 루틴

1. 사용자는 대시보드의 `다시 볼 기록`에서 1주/3개월/1년 복기 항목을 본다.
2. 항목을 눌러 과거 투자 일기로 들어간다.
3. 당시의 감정과 판단을 현재 시점에서 다시 읽는다.
4. 필요하면 복기 완료 처리하고, 배운 점을 원칙 메모에 반영한다.

### 기준 업데이트 루틴

1. 사용자는 대표 메모에서 투자 원칙, 행동 원칙, 체크리스트를 본다.
2. 복기 중 깨달음이 생기면 기존 메모를 불러온다.
3. 원칙을 한 줄 추가하거나 기존 기준을 수정한다.
4. 이 행동이 복기노트의 가장 중요한 성공 행동이다.

## 7. 페인포인트와 감정지도

### 핵심 페인포인트

| 페인포인트 | 표면적 불만 | 진짜 원인 | 필요한 UX |
| --- | --- | --- | --- |
| 메모는 쌓이는데 다시 안 본다 | "다시 보기가 귀찮다" | 기록이 날짜별로 흩어져 있고 복기 진입점이 약하다 | 대시보드에서 오늘 기록과 이번 주 복기를 바로 제안한다. |
| 여러 메모를 왔다 갔다 해야 한다 | "흐름이 끊긴다" | 읽기와 쓰기가 다른 화면에 분리되어 있다 | 원본을 이어 보여주고 복기 입력창을 읽는 위치 근처에 둔다. |
| 같은 실수를 반복한다 | "왜 또 이랬지?" | 판단 이유와 감정을 당시 맥락으로 남기지 못했다 | 템플릿으로 감정, 행동 이유, 하지 않은 이유를 기록하게 한다. |
| 시장 심리와 내 심리가 섞인다 | "내 판단인지 분위기에 휩쓸린 건지 모르겠다" | 시장 반응과 자기 감정이 구분되지 않는다 | 템플릿에서 시장 심리와 내 심리를 분리해 묻는다. |
| 복기를 놓치면 루틴이 무너진다 | "이미 늦었다" | 놓친 복기가 실패처럼 보인다 | `미완료`보다 `다시 볼 기록`이라는 표현을 쓴다. |
| 템플릿/폴더 설정이 많아지면 부담스럽다 | "이것도 관리해야 하나?" | 기록보다 관리 작업이 앞선다 | 대표 템플릿은 고정하고, 설정은 뒤로 물린다. |
| 투자 기록은 민감하다 | "남에게 보이면 안 된다" | 감정, 실수, 판단 실패가 포함된다 | 혼자 쓰는 조용한 톤과 프라이버시 신뢰를 유지한다. |

### 감정지도

| 단계 | 사용자 감정 | 위험 | 화면이 해야 할 일 |
| --- | --- | --- | --- |
| 대시보드 진입 | 오늘도 써야 하나, 뭘 하지 | 시작 부담 | 가장 큰 행동 하나를 바로 보여준다. |
| 투자 일기 작성 | 아직 감정이 생생함, 빠르게 적고 싶음 | 템플릿이 길면 중도 이탈 | 템플릿은 안내하되 입력은 자유롭게 둔다. |
| 기록 누적 | 쌓이고 있다는 안도감 | 다시 안 볼 가능성 | 최근 기록보다 복기 행동을 더 크게 둔다. |
| 주간 복기 시작 | 보기 귀찮지만 필요함 | 원본 선택이 번거로우면 포기 | `이번 주 복기 시작`으로 자동 묶음을 제공한다. |
| 원본 읽기 | 당시의 나를 다시 만남, 후회/민망함 | 자기비난 | 판단하지 않는 문구와 읽기 전용 원본을 제공한다. |
| 복기 작성 | 패턴이 보이는 느낌 | 쓰는 위치가 멀면 흐름 끊김 | 원본 가까이에서 복기 입력을 하게 한다. |
| 원칙 수정 | 깨달음을 행동으로 바꾸는 순간 | 따로 찾아가야 하면 잊어버림 | 복기 중 기존 메모를 바로 불러와 수정하게 한다. |
| 장기 복기 | 과거와 현재 비교, 성장감 | 밀린 과제로 보이면 부담 | 오늘/밀린 복기를 부드럽게 보여준다. |

## 8. 성공 정의

복기노트의 성공은 "사용자가 메모를 많이 쓴다"가 아니다.

복기노트의 성공은 사용자가 과거 기록을 다시 읽고, 그 안에서 발견한 감정/판단 패턴을 새로운 행동 원칙으로 남기는 것이다.

### 가장 중요한 관찰 가능한 행동

사용자가 `이번 주 복기 시작`을 눌러 여러 투자 일기를 읽고, 복기 내용을 작성한 뒤, 대표 메모나 원칙 메모에 하나 이상의 행동 기준을 추가하거나 수정한다.

### 핵심 성공 지표

| 우선순위 | 지표 | 의미 |
| --- | --- | --- |
| 1 | 복기 후 대표 메모 또는 원칙 메모 수정 횟수 | 복기가 실제 행동 원칙 업데이트로 이어졌는지 본다. |
| 2 | 이번 주 복기 시작 후 복기 세션 저장률 | 핵심 복기 흐름이 끝까지 작동하는지 본다. |
| 3 | 투자 일기 작성 후 1주/3개월/1년 복기 진입률 | 장기 복기 루프가 살아 있는지 본다. |
| 4 | 대표 메모 재방문 횟수 | 사용자가 원칙을 판단 순간에 다시 꺼내 보는지 본다. |
| 5 | 2주 이상 연속 사용한 사용자 수 | 습관 도구로 유지되는지 본다. |

### 화면에서 키워야 하는 것

- 오늘 기록 시작
- 이번 주 복기 시작
- 다시 볼 기록
- 대표 메모
- 복기 중 기존 메모 불러오기
- 원본 읽기와 복기 작성의 연결감

### 뒤로 물려야 하는 것

- 폴더 관리
- 템플릿 관리
- 최근 기록의 과도한 강조
- 설정, 휴지통, 계정 관리
- 수익률 차트, 점수, 등급, 평가 UI
- AI 분석이나 투자 추천

## 9. 디자인 원칙

### 1. 기록보다 복기를 전면에 둔다

복기노트의 차별점은 메모 작성이 아니라 기록을 다시 읽고 행동 원칙으로 바꾸는 흐름이다. 대시보드는 최근 기록 목록이 아니라 다음 복기 행동을 제안해야 한다.

### 2. 사용자를 평가하지 않는다

좋은 투자, 나쁜 투자, 점수, 성과 랭킹 같은 표현은 피한다. 앱은 판단하지 않고, 사용자가 자기 판단을 볼 수 있게 돕는다.

### 3. 실패처럼 보이지 않게 한다

기록하지 못한 날이나 밀린 복기는 실패가 아니다. `미완료`, `놓침`, `지연`보다 `다시 볼 기록`, `이어보기`처럼 부담이 적은 표현을 쓴다.

### 4. 흐름을 끊지 않는다

읽기와 쓰기, 복기와 원칙 수정이 다른 화면으로 흩어지면 안 된다. 깨달음이 생긴 순간 바로 기록하거나 수정할 수 있어야 한다.

### 5. 모바일에서 한 손으로 시작 가능해야 한다

핵심 행동은 iPhone Safari/PWA에서 먼저 편해야 한다. 큰 터치 영역, 짧은 문구, 명확한 첫 행동, 안정적인 입력 포커스가 중요하다.

### 6. 설정은 뒤에 둔다

템플릿과 폴더는 사용자가 기록을 시작하기 쉽게 만드는 보조 장치이다. 설정이 제품의 전면이 되면 사용자는 관리 부담을 느낀다.

## 10. 디자인 판단 질문

새 화면이나 기능을 만들 때는 아래 질문으로 판단한다.

1. 이 화면은 사용자가 투자 세계관을 정리하는 데 도움이 되는가?
2. 이 화면은 행동 원칙을 만들거나 고치는 데 도움이 되는가?
3. 이 화면은 기록을 다시 읽게 만드는가?
4. 이 화면은 복기 흐름을 덜 끊기게 하는가?
5. 이 화면은 사용자를 평가하거나 압박하지 않는가?
6. 이 화면은 모바일에서 부담 없이 시작할 수 있는가?

## 11. 참고 리서치 요약

### 트레이딩 저널

트레이딩 저널은 날짜, 종목, 손익뿐 아니라 판단 이유, 수행, 감정을 함께 기록할 때 반복 실수를 줄이는 피드백 도구가 된다. 복기노트의 템플릿은 수익률보다 시장 반응, 자기 심리, 행동 이유를 남기게 해야 한다.

### 감정적 투자

과신, 군중 추종, 공포, 충동을 줄이려면 투자 이유를 기록하고 정기적으로 다시 보는 과정이 필요하다. 복기노트의 1주/3개월/1년 복기는 단순 알림이 아니라 당시 판단과 현재 시각을 비교하는 장치이다.

### 개인 투자자의 감정 관리

개인 투자자는 시장 변동성, 손실, 직장과 투자 병행, 외로움, 감정 관리에서 부담을 크게 느낀다. 복기노트는 커뮤니티나 평가 피드백보다, 혼자 솔직하게 자기 판단을 다시 볼 수 있는 심리적으로 안전한 공간이어야 한다.
