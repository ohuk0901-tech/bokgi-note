# MVP 제품 요구사항

## 1. 목표

3개월 MVP의 목표는 사용자가 투자 일기나 기타 기록을 폴더에 작성하고, 여러 메모와 과거 복기 세션을 선택해 새 복기 세션을 만들 수 있는 웹/PWA를 출시하는 것이다.

성공 기준:

- 사용자가 2주 이상 실제 투자 일기와 주간 복기에 사용할 수 있다.
- 지인/소수 베타 사용자 최대 30명이 가입해 사용할 수 있다.
- 일반 메모와 복기 세션이 같은 폴더 안에서 자연스럽게 누적된다.
- 주간 복기 세션을 다시 선택해 월간 복기를 만들 수 있다.

## 2. 대상 사용자

- 초기 사용자: 서비스 제작자 본인
- 베타 사용자: 지인/소수 사용자 최대 30명
- 사용 언어: 한국어
- 사용 환경: 모바일 웹 최우선, 데스크톱 웹 보조
- 1차 검증 기기: iPhone Safari
- 데스크톱 웹은 개발, 긴 글 입력, 관리 작업을 보조하는 환경으로 둔다.
- 기능 완료 판단은 모바일에서 로그인, 메모 작성, 자동 저장, 복기 작성 흐름이 정상 동작하는지를 기준으로 한다.

## 3. 포함 기능

### 인증

- 이메일/비밀번호 회원가입 및 로그인
- 이메일/비밀번호 가입 시 이메일 인증 필수
- Google 로그인
- 로그아웃
- 계정 삭제

### 폴더

- 신규 사용자 기본 폴더 자동 생성
- 1단 폴더 생성
- 폴더명 수정
- 폴더 휴지통 이동
- 폴더 삭제 시 폴더 안 항목 함께 휴지통 이동
- 폴더 안 통합 목록 표시
- 중첩 폴더는 지원하지 않음

### 메모

- `+` 버튼으로 새 메모 작성
- `+` 버튼 클릭 시 `제목 없음`과 오늘 날짜를 가진 초안 즉시 생성
- 제목이 `제목 없음`이고 본문이 비어 있는 빈 초안 자동 삭제
- 제목, 본문, 날짜 입력
- 메모 수정
- 자동 저장
- 휴지통 이동
- 30일 후 완전 삭제 정책

### 목록

- 일반 메모와 복기 세션을 같은 목록에서 표시
- 기본 정렬은 `created_at` 기준 최신 등록순
- 복기 세션은 `복기` 뱃지 표시
- 제목/본문 검색
- 검색 대상은 일반 메모와 복기 세션 모두 포함
- MVP 검색은 단순 부분검색으로 시작

### 복기

- 체크박스로 복기 원본 선택
- 원본으로 일반 메모와 과거 복기 세션 모두 선택 가능
- 원본 최대 6개 선택
- 선택된 원본은 메모의 날짜와 복기 세션의 복기 날짜 기준 오래된 순으로 표시
- 복기 모드에서 원본 항목은 읽기 전용
- 복기 입력창은 원본 항목 사이로 이동 가능
- 복기 화면 진입 시 `YYYY.MM.DD 복기` 제목의 초안 복기 세션 즉시 생성
- 복기 제목은 자동 생성 후 사용자가 수정 가능
- 복기 결과는 현재 폴더에 복기 세션으로 저장
- 복기 세션은 나중에 다시 열어 수정 가능
- 복기 세션은 다시 다른 복기의 원본으로 선택 가능
- 원본 스냅샷은 저장하지 않고 항상 최신 원본 내용을 표시

### 기존 메모 수정

- 복기 중 기존 메모를 최대 3개까지 불러오기
- 불러온 기존 메모는 복기 화면에서 수정 가능
- 수정 내용은 원본 메모에 즉시 자동 저장

### PWA

- 홈 화면 설치를 위한 PWA 기본 설정
- 앱 이름은 임시로 `복기노트`
- 아이콘은 임시 기본 아이콘 사용

## 4. 제외 기능

- AI 분석
- 투자 종목 추천
- 수익률 분석
- 증권사 계좌 연동
- 자동 매매 기록 연동
- 태그
- 달력 뷰
- 중첩 폴더
- 완전한 오프라인 작성
- 앱스토어/플레이스토어 정식 배포
- 협업 기능
- 복잡한 통계 대시보드
- Markdown/CSV 내보내기
- 비로그인 데모

## 5. 주요 사용자 시나리오

### 새 메모 작성

1. 사용자가 로그인한다.
2. 폴더를 연다.
3. `+` 버튼을 누른다.
4. `제목 없음`과 오늘 날짜를 가진 초안 메모가 즉시 생성된다.
5. 제목, 본문, 날짜를 입력한다.
6. 내용은 자동 저장된다.
7. 사용자가 아무것도 작성하지 않고 나가면 빈 초안은 자동 삭제된다.

### 주간 복기 작성

1. 사용자가 폴더를 연다.
2. 월요일부터 토요일까지의 투자 일기 6개를 체크박스로 선택한다.
3. 복기 시작을 누른다.
4. `YYYY.MM.DD 복기` 제목의 초안 복기 세션이 즉시 생성된다.
5. 선택된 메모들이 메모 날짜 기준 오래된 순으로 표시된다.
6. 사용자는 원본 메모 사이로 복기 입력창을 이동하며 복기 내용을 작성한다.
7. 필요하면 기존 메모를 최대 3개까지 불러와 수정한다.
8. 불러온 기존 메모 수정 내용은 원본 메모에 즉시 자동 저장된다.
9. 복기 결과는 현재 폴더에 복기 세션으로 자동 저장된다.
10. 폴더 목록에는 `복기` 뱃지가 붙은 항목으로 표시된다.

### 월간 복기 작성

1. 사용자가 폴더를 연다.
2. 4개의 주간 복기 세션을 선택한다.
3. 복기 시작을 누른다.
4. 과거 복기 세션들이 복기 날짜 기준 오래된 순으로 원본 항목에 표시된다.
5. 사용자는 월간 복기 내용을 작성한다.
6. 월간 복기 결과도 현재 폴더에 복기 세션으로 저장된다.

## 6. 수용 기준

- 회원가입한 사용자는 자신의 폴더, 메모, 복기 세션만 볼 수 있다.
- 신규 사용자는 첫 가입 또는 첫 로그인 후 `기본` 폴더를 가진다.
- 이메일/비밀번호 가입 사용자는 이메일 인증을 완료해야 사용할 수 있다.
- 폴더 안에서 `+` 버튼으로 메모를 만들 수 있다.
- `+` 버튼으로 만든 빈 초안은 제목/본문이 비어 있으면 자동 삭제된다.
- 일반 메모와 복기 세션이 같은 목록에 표시된다.
- 복기 세션은 `복기` 뱃지로 구분된다.
- 일반 메모와 복기 세션 모두 복기 원본으로 선택할 수 있다.
- 원본을 7개 이상 선택하려고 하면 제한 안내가 표시된다.
- 복기 중 기존 메모를 4개 이상 불러오려고 하면 제한 안내가 표시된다.
- 자동 저장 실패 시 사용자가 알 수 있어야 한다.
- 휴지통 항목은 일반 목록에 보이지 않는다.
- 휴지통 항목은 30일 후 삭제 대상이 되며 정리용 서버 함수로 완전 삭제할 수 있어야 한다.
- 검색은 제목과 본문을 대상으로 동작한다.
