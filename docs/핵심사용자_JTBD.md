# 핵심 사용자 JTBD

## 1. 문서 목적

이 문서는 복기노트의 핵심 사용자가 앱을 통해 진짜로 끝내려는 일을 JTBD 방식으로 정리한 문서이다.

JTBD는 Jobs To Be Done의 약자로, 사용자가 특정 제품을 사용할 때 단순히 어떤 기능을 쓰는지가 아니라, 그 기능을 통해 어떤 일을 끝내고 싶은지를 보는 관점이다.

복기노트의 경우 사용자는 단순히 메모를 저장하려는 것이 아니다.

사용자는 매일의 투자 판단, 감정, 행동 이유를 기록하고 다시 읽으면서 자기만의 투자 세계관, 행동 원칙, 투자 근육을 키우고 싶어 한다.

## 2. 핵심 JTBD 한 문장

내가 매일 투자하면서 흔들리거나 충동적으로 판단할 때, 나중에 그 순간의 생각과 감정을 다시 볼 수 있게 기록하고 복기해서, 장기적으로 나만의 투자 원칙과 투자 근육을 만들고 싶다.

## 3. JTBD 구조

| 구분 | 내용 |
| --- | --- |
| 상황 | 투자 판단, 감정, 행동 이유가 매일 흩어지고 시간이 지나면 왜 그렇게 생각했는지 흐려질 때 |
| 사용자가 원하는 일 | 과거의 기록을 쉽게 다시 읽고, 내 판단과 감정 패턴을 발견하고 싶다 |
| 기대하는 변화 | 흔들리지 않는 투자 기준, 행동 원칙, 투자 세계관을 만들고 싶다 |

## 4. 사용자의 핵심 문제

| 핵심 문제 | 사용자가 느끼는 감정 |
| --- | --- |
| 메모는 쌓이는데 다시 보기가 어렵다 | 귀찮음, 막막함 |
| 투자 판단의 이유가 시간이 지나면 사라진다 | 아쉬움, 불안 |
| 같은 실수를 반복한다 | 답답함, 자기불신 |
| 시장 심리와 내 심리가 섞인다 | 혼란, 충동 |
| 기준 메모와 일기 메모가 분리되어 있다 | 흐름 끊김 |
| 주말 복기를 하려면 여러 메모를 오가야 한다 | 피로감, 포기하고 싶음 |
| 기록을 못 한 날이 생기면 루틴이 끊긴 것처럼 느껴진다 | 부담감, 포기감 |

## 5. 기능별 JTBD

| 사용자가 하려는 일 | JTBD 문장 |
| --- | --- |
| 매일 투자 일기 쓰기 | 오늘 시장과 내 감정을 빠르게 기록해서, 나중에 왜 그렇게 판단했는지 잃어버리지 않고 싶다. |
| 이번 주 복기하기 | 이번 주 기록들을 한 번에 읽으며 반복된 감정, 행동, 실수를 발견하고 다음 주 원칙으로 바꾸고 싶다. |
| 1주/3개월/1년 뒤 다시 보기 | 시간이 지난 뒤 과거의 나를 다시 보며, 당시 판단이 단기 감정이었는지 장기 기준이었는지 확인하고 싶다. |
| 대표 메모 보기 | 자주 지켜야 할 투자 원칙과 행동 기준을 쉽게 꺼내 보며, 판단 순간에 기준을 잊지 않고 싶다. |
| 복기 중 기존 메모 수정 | 깨달음이 생긴 순간 바로 행동 원칙에 반영해서, 복기가 단순 감상이 아니라 기준 업데이트로 이어지게 하고 싶다. |
| 템플릿으로 작성하기 | 매번 무엇을 써야 할지 고민하지 않고, 시장/포트폴리오/심리/행동을 빠짐없이 점검하고 싶다. |
| 밀린 복기 확인하기 | 놓친 복기를 직접 찾아다니지 않고, 다시 봐야 할 기록을 앱이 조용히 알려주면 좋겠다. |
| 고정 메모 관리하기 | 지금의 나에게 중요한 기준과 원칙을 대시보드에서 바로 확인하고 싶다. |

## 6. 감정적 JTBD

복기노트는 사용자가 더 똑똑한 투자자처럼 보이게 만드는 앱이 아니라, 사용자가 내가 왜 흔들렸는지를 볼 수 있게 돕는 앱이다.

| 사용자의 감정 | 앱이 해줘야 하는 역할 |
| --- | --- |
| 불안 | 판단을 강요하지 않고 조용히 기록하게 해준다. |
| 후회 | 실수를 다시 볼 수 있게 하되 비난하지 않는다. |
| 혼란 | 시장 심리와 내 심리를 나눠 보게 한다. |
| 귀찮음 | 한 번의 버튼으로 기록과 복기를 시작하게 한다. |
| 자기불신 | 과거 기록을 통해 나아지고 있다는 감각을 준다. |
| 고립감 | 혼자 써도 내 생각을 붙잡아주는 작업대가 된다. |
| 부담감 | 밀린 기록과 복기를 실패로 보이게 하지 않고 다시 이어갈 수 있게 한다. |

## 7. 복기노트가 진짜로 끝내야 하는 일

복기노트의 최종 목적은 메모를 잘 저장하는 것이 아니다.

복기노트가 끝내야 하는 일은 사용자가 매일의 투자 판단을 기록하고, 주기적으로 다시 읽고, 깨달음을 행동 원칙으로 바꾸게 해서, 자기만의 투자 세계관과 투자 근육을 만드는 것이다.

따라서 복기노트는 투자 결과를 평가하거나 수익률을 분석하는 앱보다, 사용자가 자기 판단을 훈련하는 복기 작업대에 가깝다.

## 8. UX 기준

| 해야 하는 것 | 피해야 하는 것 |
| --- | --- |
| 오늘 기록을 쉽게 시작하게 하기 | 복잡한 대시보드 차트 |
| 이번 주 복기를 눈에 잘 보이게 하기 | 수익률 중심 평가 |
| 밀린 복기를 부담 없이 보여주기 | 사용자를 혼내는 문구 |
| 대표 메모를 바로 꺼내 보게 하기 | 과도한 설정 |
| 복기 중 원칙을 바로 수정하게 하기 | 메모 간 이동을 많이 요구하는 흐름 |
| 조용히 자동 저장하기 | 계속 저장 상태를 강조하는 UI |
| 모바일에서 한 손으로 시작 가능하게 하기 | 데스크톱 중심의 복잡한 화면 |

## 9. 화면과 문구에 적용할 원칙

### 행동 중심 문구를 쓴다

좋은 예:

```text
투자 일기 작성하기
투자 일기 이어쓰기
이번 주 복기 시작
다시 볼 기록
대표 메모
```

피해야 할 예:

```text
템플릿 실행
세션 생성
데이터 입력
객체 선택
```

### 사용자를 평가하지 않는다

앱은 사용자의 투자 판단을 평가하지 않는다.

좋은 투자, 나쁜 투자, 점수, 등급, 성과 랭킹 같은 표현은 복기노트의 핵심 정서와 맞지 않는다.

### 실패처럼 보이지 않게 한다

기록을 못 한 날이나 밀린 복기는 실패가 아니다.

사용자가 다시 이어갈 수 있도록 조용히 보여주는 것이 좋다.

좋은 예:

```text
다시 볼 기록이 있어요
지난 기록을 이어서 볼 수 있어요
```

피해야 할 예:

```text
복기를 놓쳤습니다
미완료 항목
지연된 작업
```

## 10. 제품 판단 기준

새 기능을 추가하거나 디자인을 바꿀 때는 다음 질문으로 판단한다.

1. 이 기능이 사용자의 투자 세계관 정리에 도움이 되는가?
2. 이 기능이 행동 원칙을 만들거나 고치는 데 도움이 되는가?
3. 이 기능이 복기 흐름을 덜 끊기게 하는가?
4. 이 기능이 매일 기록 습관을 더 쉽게 만드는가?
5. 이 기능이 사용자를 평가하거나 분석 대상으로 만들지는 않는가?
6. 이 기능이 모바일에서 부담 없이 쓸 수 있는가?

## 12. 최종 JTBD 기준 문장

복기노트는 사용자가 투자 판단을 대신 맡기기 위해 쓰는 앱이 아니다.

복기노트는 사용자가 과거의 나를 다시 읽고, 감정과 행동 패턴을 알아차리고, 자기만의 투자 세계관과 행동 원칙을 만들어 투자 근육을 기르기 위해 쓰는 앱이다.
