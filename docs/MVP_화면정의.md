# MVP 화면 정의

## 1. 로그인 화면

경로:

```text
/login
```

기능:

- 이메일/비밀번호 회원가입
- 이메일/비밀번호 로그인
- Google 로그인 제외
- 로그인 실패 메시지 표시
- 이메일 인증 안내 표시

원칙:

- 한국어만 사용한다.
- 비로그인 데모는 제공하지 않는다.
- 이메일/비밀번호 가입 사용자는 이메일 인증을 완료해야 앱을 사용할 수 있다.

## 2. 폴더 목록 화면

경로:

```text
/folders
```

기능:

- 사용자의 폴더 목록 표시
- 새 폴더 생성
- 폴더명 수정
- 폴더 휴지통 이동
- 기본 폴더 제공

기본 폴더:

- 신규 사용자는 첫 가입 또는 첫 로그인 시 `기본` 폴더를 자동으로 가진다.
- 기본 폴더가 없으면 앱 진입 시 생성한다.

표시:

- 폴더명
- 폴더 안 항목 수
- 최근 수정일

제외:

- 중첩 폴더
- 달력 뷰

## 3. 폴더 상세 화면

경로:

```text
/folders/[id]
```

기능:

- 해당 폴더의 일반 메모와 복기 세션 통합 목록 표시
- `+` 버튼으로 새 메모 생성
- 체크박스로 복기 원본 선택
- 선택한 항목으로 복기 시작
- 제목/본문 검색
- 항목 휴지통 이동

`+` 버튼 동작:

- 클릭 즉시 `제목 없음`과 오늘 날짜를 가진 초안 메모를 생성한다.
- 생성 후 메모 작성 화면으로 이동한다.

표시:

- 일반 메모: 제목, 미리보기, 날짜
- 복기 세션: 제목, `복기` 뱃지, 미리보기, 날짜

정렬:

- MVP 기본값은 `created_at` 기준 최신 등록순

선택 규칙:

- 일반 메모와 복기 세션 모두 선택 가능
- 최대 6개까지 선택 가능
- 7개 이상 선택 시 제한 안내 표시

## 4. 메모 작성/수정 화면

경로:

```text
/notes/new
/notes/[id]
```

기능:

- 제목 입력
- 날짜 입력
- 본문 입력
- 자동 저장
- 저장 상태 표시
- 휴지통 이동

필수값:

- 제목
- 본문
- 날짜

저장 상태:

```text
저장 중
저장됨
저장 실패
```

원칙:

- 저장 버튼은 두지 않는다.
- 사용자는 일반 메모 화면에서 메모를 수정할 수 있다.
- 새 메모의 기본 제목은 `제목 없음`이다.
- 새 메모의 기본 날짜는 오늘 날짜이다.
- 제목이 `제목 없음`이고 본문이 비어 있는 상태로 화면을 나가면 빈 초안은 자동 삭제한다.

## 5. 복기 작성 화면

경로:

```text
/reviews/new
```

진입:

- 폴더 상세 화면에서 일반 메모 또는 복기 세션을 최대 6개 선택한 뒤 진입한다.

구성:

```text
[복기 제목]
[복기 날짜]

[원본 항목 1]
[여기로 복기 입력창 이동]

[원본 항목 2]
[여기로 복기 입력창 이동]

[복기 입력창]

[기존 메모 불러오기]
[불러온 기존 메모 편집 영역]
```

기능:

- 복기 제목 입력
- 복기 날짜 입력
- 선택된 원본 항목 읽기
- 복기 입력창 작성
- 복기 입력창 위치 이동
- 기존 메모 최대 3개 불러오기
- 불러온 기존 메모 수정
- 자동 저장

초안 생성:

- 복기 작성 화면에 진입하면 즉시 초안 복기 세션을 생성한다.
- 기본 제목은 `YYYY.MM.DD 복기` 형식이다.
- 기본 복기 날짜는 오늘 날짜이다.
- 기본 제목과 빈 본문 상태로 화면을 나가면 빈 복기 초안은 자동 삭제한다.

원본 항목 표시:

- 일반 메모: 제목, 날짜, 본문
- 복기 세션: 제목, `복기` 뱃지, 날짜, 본문

규칙:

- 원본 항목은 읽기 전용이다.
- 원본 항목은 메모의 `note_date`와 복기 세션의 `review_date` 기준 오래된 순으로 표시한다.
- 복기 입력창은 하나만 존재한다.
- 복기 세션은 현재 폴더에 저장한다.
- 원본 스냅샷은 저장하지 않는다.
- 불러온 기존 메모 수정 내용은 원본 메모에 즉시 자동 저장한다.

## 6. 복기 보기/수정 화면

경로:

```text
/reviews/[id]
```

기능:

- 기존 복기 세션 열람
- 복기 제목/날짜/본문 수정
- 원본 항목 최신 내용 표시
- 복기 입력창 위치 수정
- 기존 메모 불러오기 및 수정
- 자동 저장

원칙:

- 복기 세션 자체는 수정 가능하다.
- 복기 원본 항목은 최신 내용을 보여준다.
- 원본 항목은 읽기 전용이다.

## 7. 휴지통 화면

경로:

```text
/trash
```

기능:

- 휴지통으로 이동된 폴더, 메모, 복기 세션 표시
- 복원
- 즉시 완전 삭제
- 30일 후 완전 삭제 예정일 표시

규칙:

- 휴지통 항목은 일반 목록과 검색 결과에 표시하지 않는다.
- 30일 후 완전 삭제 정책을 따른다.
- 완전 삭제 대상 처리는 `purge_deleted_items` 정리용 서버 함수로 수행한다.

## 8. 설정 화면

경로:

```text
/settings
```

기능:

- 로그인 계정 정보 표시
- 로그아웃
- PWA 설치 안내
- 계정 삭제

계정 삭제:

- 삭제 전 확인 문구를 표시한다.
- 사용자 화면에서는 즉시 삭제 처리한다.
- 계정 삭제 요청 시 사용자 데이터는 soft delete 처리한다.
- 사용자는 즉시 로그아웃된다.
- 삭제 요청 상태의 사용자가 다시 접근하면 앱 화면 진입을 차단한다.
- 내부 데이터는 30일 후 완전 삭제 정책을 따른다.

## 9. 빈 상태와 오류 상태

빈 폴더:

- 아직 메모가 없음을 알린다.
- `+` 버튼으로 새 메모를 만들 수 있게 한다.

검색 결과 없음:

- 검색 결과가 없음을 알린다.

자동 저장 실패:

- `저장 실패` 상태를 표시한다.
- 재시도할 수 있게 한다.

선택 제한 초과:

- 복기 원본 6개 초과 또는 기존 메모 3개 초과 시 제한 안내를 표시한다.
