# 베타 공유 운영 체크리스트

복기노트를 10~30명 규모의 베타 사용자에게 공유하기 전에 확인할 항목입니다.

## 1. Supabase 인증 설정

Supabase Dashboard에서 아래 값을 확인한다.

- Authentication → URL Configuration
  - Site URL: `https://bokgi-note.vercel.app`
  - Redirect URLs:
    - `https://bokgi-note.vercel.app/auth/callback`
    - `https://bokgi-note.vercel.app/reset-password`
- Authentication → Providers
  - Email provider가 켜져 있는지 확인한다.
  - Google 로그인은 베타에서 사용하지 않는다.

## 2. Vercel 환경변수

Vercel Project Settings → Environment Variables에서 운영 환경에 아래 값을 설정한다.

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `ADMIN_JOB_SECRET`
- `NEXT_PUBLIC_SITE_URL=https://bokgi-note.vercel.app`
- `NEXT_PUBLIC_CONTACT_EMAIL`

실제 키는 문서나 GitHub에 적지 않는다.

## 3. 삭제와 정리 정책

- 앱의 계정 삭제는 사용자 데이터를 즉시 숨기고 30일 후 완전 삭제 대상으로 표시한다.
- 30일이 지난 데이터는 `/api/purge-deleted`를 관리자 비밀키로 호출해야 정리된다.
- 베타 단계에서는 수동 호출로 시작하고, 사용자가 늘어나면 Vercel Cron으로 자동화한다.

## 4. 베타 공유 전 테스트

- 새 이메일로 가입하고 인증 메일을 확인한다.
- 이메일 로그인 후 대시보드에 들어간다.
- 비밀번호 재설정 메일을 보내고 새 비밀번호로 로그인한다.
- 투자 일기 작성, 이번 주 복기, 대표 메모 고정, 휴지통 복원을 확인한다.
- `/privacy`, `/terms` 페이지가 로그인 전에도 열리는지 확인한다.
- Vercel Web Analytics가 Vercel 대시보드에서 수집되는지 확인한다.

## 5. 사용자 안내 문구

베타 사용자에게 아래 내용을 함께 안내한다.

- 이 앱은 투자 조언 서비스가 아니라 투자 판단을 기록하고 복기하는 도구다.
- 계좌번호, 주민등록번호, 인증번호, 거래소 API 키 같은 민감정보는 입력하지 않는다.
- 베타 중 화면과 기능이 바뀔 수 있다.
- 불편한 점은 운영자에게 알려준다.
