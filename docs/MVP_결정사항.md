# MVP 결정사항

## 1. 제품 방향

- 임시 서비스명은 `복기노트`이다.
- 첫 MVP는 웹/PWA로 출시한다.
- 나중에 Expo/React Native 기반 모바일 앱으로 확장한다.
- 초기 사용자는 본인과 지인/소수 베타 사용자이며, 운영 기준은 최대 30명이다.
- 회원가입은 공개로 열어둔다.
- 서비스 언어는 한국어만 지원한다.
- 비로그인 체험용 데모는 제공하지 않는다.
- 초기 배포는 Vercel 기본 주소를 사용한다.
- 정식 도메인과 브랜드 아이콘은 나중에 정한다.

## 2. 핵심 제품 결정

- 첫 화면은 폴더/메모 흐름으로 진입한다.
- 디자인은 아이폰 메모장처럼 단순한 생산성 도구를 지향한다.
- 모바일 웹 사용성을 우선한다.
- 메모 생성은 `+` 버튼으로 시작한다.
- `+` 버튼을 누르면 `제목 없음`과 오늘 날짜를 가진 초안 메모를 즉시 생성한다.
- 제목이 `제목 없음`이고 본문이 비어 있는 상태로 화면을 나가면 빈 초안 메모는 자동 삭제한다.
- 메모 필수값은 제목, 본문, 날짜이다.
- 태그는 MVP에서 제외한다.
- 달력 뷰는 MVP에서 제외한다.
- 폴더는 1단 구조만 지원한다.
- 신규 사용자는 첫 가입 또는 첫 로그인 시 `기본` 폴더가 자동 생성된다.
- 폴더를 삭제하면 폴더와 안의 일반 메모/복기 세션이 모두 휴지통으로 이동한다.
- 폴더 안 목록은 일반 메모와 복기 세션을 함께 최신 등록순으로 보여준다.
- 검색은 일반 메모와 복기 세션의 제목/본문을 모두 대상으로 한다.
- 검색은 MVP에서 단순 부분검색으로 시작한다.

## 3. 복기 관련 결정

- 복기 결과는 내부적으로 `review_sessions`에 저장한다.
- 복기 세션은 폴더 목록에서 일반 메모처럼 보인다.
- 복기 세션 제목 옆에는 `복기` 뱃지를 표시한다.
- 복기 세션은 현재 폴더에 저장한다.
- 복기 화면에 진입하면 `YYYY.MM.DD 복기` 형식의 제목을 가진 초안 복기 세션을 즉시 생성한다.
- 복기 제목은 자동 생성되지만 사용자가 수정할 수 있다.
- 일반 메모와 과거 복기 세션 모두 새 복기 원본으로 선택할 수 있다.
- 복기 원본은 최대 6개까지 선택할 수 있다.
- 복기 중 원본 항목은 읽기 전용이다.
- 복기 세션을 다시 열면 원본 항목은 최신 내용을 보여준다.
- 원본 항목의 스냅샷은 저장하지 않는다.
- 복기 원본 정렬은 메모의 `note_date`와 복기 세션의 `review_date`를 기준으로 오래된 순으로 처리한다.
- 복기 세션 자체는 나중에 다시 열어 수정할 수 있다.
- 복기 입력창은 원본 항목 사이로 이동할 수 있다.
- 입력창 이동은 버튼 또는 화살표 방식으로 구현한다.
- 복기 중 불러와 수정할 기존 메모는 최대 3개까지 허용한다.
- 복기 중 불러온 기존 메모는 수정 즉시 원본 메모에 자동 저장한다.

## 4. 저장 및 삭제 결정

- 메모와 복기 세션은 자동 저장한다.
- 저장 버튼은 두지 않는다.
- 화면에는 `저장 중`, `저장됨`, `저장 실패` 상태를 표시한다.
- 삭제는 즉시 완전 삭제가 아니라 휴지통 이동으로 처리한다.
- 휴지통 항목은 `delete_after` 기준 30일 후 완전 삭제한다.
- 30일 후 완전 삭제는 `purge_deleted_items` 정리용 서버 함수로 처리한다.
- 계정 삭제 기능은 MVP에 포함한다.
- 계정 삭제 시 사용자 화면에서는 즉시 삭제 처리하고, 내부 데이터는 30일 후 완전 삭제 정책을 따른다.
- 계정 삭제 요청 시 사용자 데이터는 soft delete 처리하고 사용자는 로그아웃된다.

## 5. 인증 및 운영 결정

- 인증은 Supabase Auth를 사용한다.
- 이메일/비밀번호 로그인을 제공한다.
- 이메일/비밀번호 가입은 이메일 인증을 필수로 한다.
- Google 로그인을 제공한다.
- MVP는 무료 서비스로 시작한다.
- Supabase/Vercel 유료 플랜은 필요해질 때만 올린다.
- 정식 공개 전 개인정보 처리방침과 이용약관을 준비한다.

## 6. MVP 제외 결정

- AI 분석 제외
- 투자 종목 추천 제외
- 수익률 분석 제외
- 증권사 계좌 연동 제외
- 자동 매매 기록 연동 제외
- 태그 제외
- 달력 뷰 제외
- 중첩 폴더 제외
- 완전한 오프라인 작성 제외
- 앱스토어/플레이스토어 정식 배포 제외
- 협업 기능 제외
- Markdown/CSV 내보내기 제외

## 7. 개발에 필요한 임시값

- 임시 서비스명: `복기노트`
- 임시 배포 주소: Vercel 기본 주소
- 임시 PWA 아이콘: 기본 아이콘
- 기본 폴더명: `기본`
- 복기 뱃지 텍스트: `복기`
